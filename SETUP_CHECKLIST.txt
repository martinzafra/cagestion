================================================================================
TROUBLESHOOTING
================================================================================

Issue: "Table already exists" error
  Cause: Schema partially or fully already applied
  Solution:
    1. Go to: SQL Editor > New Query
    2. Run: DROP TABLE IF EXISTS [table_name] CASCADE;
    3. Drop all tables: bookings, expenses, revenue_invoicing, users, inventory_*
    4. Run: DROP TYPE IF EXISTS [type_name];
    5. Drop all enums: user_role, booking_status, price_basis, task_status, revenue_type, expense_type_enum, yes_no_na
    6. Re-run SETUP_SCHEMA.sql

Issue: "Permission denied" error
  Cause: User doesn't have admin privileges
  Solution:
    1. Use admin Supabase account
    2. Or contact Supabase support to elevate permissions
    3. Verify you're not using anon key for direct queries

Issue: Seed data not inserting
  Cause: Schema not created yet, or foreign keys missing
  Solution:
    1. Verify SETUP_SCHEMA.sql ran successfully
    2. Re-run SETUP_SCHEMA.sql first
    3. Then run SEED_DATA.sql

Issue: Can't find project
  Cause: Wrong project ID or not logged in
  Solution:
    1. Verify project ID: sajrwsfpvkitqubvzotc
    2. Log in to Supabase: https://app.supabase.com
    3. Double-check project is visible in dashboard

Issue: CLI authentication fails
  Cause: Access token missing or expired
  Solution:
    1. Run: supabase logout
    2. Run: supabase login
    3. Generate fresh access token from Supabase dashboard
    4. Paste when prompted

Issue: Generated columns not calculating
  Cause: Column type or formula incorrect
  Solution:
    1. Go to: Database > Tables
    2. Click on affected table
    3. Check: Column definition shows GENERATED ALWAYS AS ... STORED
    4. If missing, run SETUP_SCHEMA.sql again
